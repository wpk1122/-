# Chrona 0.1.0 发布说明

发布日期：2026-05-20

## 版本定位

Chrona 0.1.0 是 AI 智能日程助手的发布候选版，面向真机安装测试、功能演示和后续商店签名发布准备。

## 核心功能

- 自然语言日程输入：支持一句话拆分多个事项。
- 用户自填 API：支持 OpenAI-compatible 接口配置，可使用 DeepSeek 等兼容服务。
- 当前时间注入：API 请求会提供手机当前系统时间和时区，减少“明天、今晚、周末”等相对时间解析错误。
- 长文本稳定解析：长输入自动分段请求，降低超时和上下文超限风险。
- 本地回退解析：未配置 API、API 失败或返回空结果时自动使用本地规则解析。
- 日程确认与保存：解析结果先确认，再写入本地 Room 数据库。
- 通知提醒：有明确时间的任务通过 WorkManager 安排系统通知。
- 本地行为洞察：记录创建、完成、删除行为，用于完成率、高效时段、过期待办和建议生成。
- 无人物应用界面：页面内容使用组件化时间管理视觉；人物头像仅作为应用图标。

## 交付物说明

- `Chrona-0.1.0-debug.apk`：可直接安装测试的 debug 签名 APK。
- `Chrona-0.1.0-release-unsigned.apk`：未签名 release APK，供正式 keystore 签名后分发。
- `Chrona-0.1.0-release-unsigned.aab`：未签名 Android App Bundle，供正式 keystore 签名后提交商店。
- `chrona-ui-preview.html`：可离线打开的界面预览文件。
- `Chrona-source-0.1.0.zip`：源码快照。
- `checksums-sha256.txt`：交付文件 SHA-256 校验值。

## 发布前注意

正式上架前必须使用你自己的私有 keystore 进行签名；不要把临时测试签名当作正式发布签名。
